# Архитектура Ritela

Сейчас один Android-модуль `app`. `MainActivity` настраивает защищённое окно и edge-to-edge, `ui/RitelaApp.kt` содержит стартовый экран, `ui/Theme.kt` — тему и интервалы. Kotlin встроен в AGP 9.4.1; отдельный kotlin-android plugin не применяется.

Реализована базовая запись менструального периода. `domain/Period.kt` содержит чистые Kotlin-модель и проверку дат. `data/` содержит Room database/DAO, storage entity и repository. `RitelaApplication` создаёт единственный экземпляр базы лениво, `PeriodViewModel` передаёт состояние через StateFlow. UI наблюдает его с учётом lifecycle.

Новая запись содержит начало и необязательное окончание. Открытый период можно завершить позже. Repository запрещает будущие/обратные даты; DAO проверяет пересечения и вставляет в одной транзакции. Даты хранятся как epoch day, технические timestamps — миллисекунды UTC. Repository читает всю историю для календаря и расчёта; главный экран показывает графики, история доступна в календаре.

Правки дат и удаление реализованы через repository/ViewModel. DAO редактирует в транзакции, проверяя overlap без самой записи и сохраняя UUID/createdAt; UI требует подтверждение удаления. Схемы Room v1/v2 экспортируются в `app/schemas/`; destructive fallback не используется. Для отметок дня добавлена day_logs с явной MIGRATION_1_2; миграция сохраняет periods. Схема и проверки: [DATA_FORMAT.md](docs/DATA_FORMAT.md).

`domain/CyclePrediction.kt` вычисляет день цикла, стартовую оценку 28/5, затем медиану/MAD и 12 расширяющихся диапазонов. После завершения записи её длительность заменяет исходную; до трёх интервалов длина цикла берётся из настроек. ViewModel combines Room Flow и Settings Flow, обновляет сегодня при ON_RESUME. Производные прогнозы не сохраняются. [Формулы и ограничения](docs/PREDICTION.md).

`CalendarScreen` использует VerticalPager для месяцев, общую MonthGrid на всю ширину и MonthYearPicker со списком годов/сеткой месяцев. `PeriodEntry` — полноэкранный Dialog с той же MonthGrid: выбор начала/окончания и выделение диапазона, быстрый выбор длительности, закреплённое сохранение; picker отдельных дат оставлен как дополнительный способ. Нижняя навигация содержит Сегодня/Календарь/Настройки. SettingsRepository хранит два исходных числовых значения в приватных SharedPreferences и публикует StateFlow; запись выполняется в Dispatchers.IO. Медицинские записи остаются в Room. DayLogRepository и четвёртый Room Flow передают отметки боли, выделений, настроения, энергии, секса и заметку. Неотмеченное значение отличается от явного NONE.

Тема и тексты соответствуют [STYLE_GUIDE.md](docs/STYLE_GUIDE.md): общие цветовые/типографические tokens, единый SansSerif для всех надписей, адаптивный Canvas-декор без bitmap assets. Системные dynamic colors по умолчанию выключены. Английский fallback в values, полный русский в values-ru. AGP generateLocaleConfig + localeFilters en/ru предоставляют системный выбор языка на Android 13+; более старые ОС используют язык устройства.

Сборка использует version catalog, Gradle wrapper с SHA-256, configuration cache и build cache. Производственные зависимости — Compose/Material 3, AndroidX Activity/Lifecycle и Room; Robolectric и ktlint используются только для проверок.

Insights рисует длины циклов/длительность и боль за неделю по фактическим записям, с текстовыми значениями. Главная не содержит список истории. Медианы берутся за последние 12 месяцев, максимум 12 наблюдений; до трёх интервалов прогноз использует legacy preset 28. HelpCards — офлайн-каталог из 18 EN/RU статей с источниками, подбор по явным симптомам и справочные взрослые дозы за подтверждением. BackupRepository обеспечивает шифрованный snapshot и транзакционный merge; BackupActions использует системный SAF. См. [карточки](docs/HEALTH_CONTENT.md) и [backup](docs/BACKUP.md).
