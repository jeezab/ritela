# Экспорт и импорт

Настройки → Экспорт данных → пароль и повтор → системный выбор файла. Импорт: выбрать `.ritela`, ввести пароль, посмотреть количество записей и подтвердить. Пароль не сохраняется; его восстановление не предусмотрено. Файл переносится между устройствами с паролем, без аккаунта.

Копия содержит все месячные (UUID, даты, createdAt/updatedAt) и отметки дня, включая секс и заметки. Язык, тема и legacy presets не входят: импорт сохраняет настройки устройства. Текущая реализация импортирует только собственный формат, без CSV/чужих трекеров. Merge сохраняет существующие записи, пропускает полностью одинаковые и отменяет всю транзакцию при конфликте UUID/дат/отметки дня. Замена базы не реализована; удаление текущих данных не требуется.

Внешний JSON: format=`ritela.backup`, version=1, iterations=600000, salt/iv/data в Base64. Внутренний JSON version=1 содержит массивы periods и days. Применяется AES-256-GCM, tag 128 бит, случайные salt 16 байт и IV 12 байт, AAD=`ritela.backup:1`; ключ PBKDF2-HMAC-SHA256, 600000 итераций. Это выбранная стандартная схема, не собственный шифр. Work factor соотнесён с [OWASP PBKDF2 guidance](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html); пароль остаётся важной частью защиты.

Пароль экспорта: 12–256 символов. Массивы символов/производного ключа очищаются по завершении; managed-memory строки JSON/поля UI нельзя гарантированно стереть из heap. Потерянный пароль делает копию недоступной. База на устройстве пока не зашифрована. Сам факт/размер файла и имя с датой видны выбранному файловому провайдеру. Пользователь может выбрать облачный провайдер в системном picker; приложение само ничего не отправляет.

Ограничения: файл ≤3 MiB, plaintext ≤2 MiB, ≤10000 periods и ≤10000 day logs; версии и work factor проверяются до KDF. Проверяются UUID, даты/пересечения, timestamps, enum/сочетания отметок и длина заметки. Неверный пароль и повреждение ciphertext не открывают preview. Все изменения Room проходят единую транзакцию. Доступ к файлам через [Storage Access Framework](https://developer.android.com/training/data-storage/shared/documents-files), без широких storage permissions. UI не делает persistable URI grants, временный доступ нужен только для текущей операции.

JVM-тесты проверяют round-trip в другую базу, сохранность дат/UUID/заметок, повторный merge, неверный пароль, изменение ciphertext, rollback конфликтов, будущие дни, неизвестную версию, чрезмерный work factor/размер и короткий пароль. Системный файловый picker, поведение облачных провайдеров и медленный телефон требуют device smoke test.
