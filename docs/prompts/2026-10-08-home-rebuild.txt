Ты работаешь над Ritela — Android / Kotlin / Jetpack Compose.

Предыдущая попытка редизайна НЕ достигла цели.

Текущий интерфейс всё ещё выглядит почти как исходный MVP:
- белый / кремовый плоский фон;
- обычные Material-компоненты;
- слишком много пустого пространства;
- орбита визуально слабая;
- календарь выглядит утилитарно;
- celestial-botanical premium style практически отсутствует.

Эта задача НЕ является incremental polish.

Нужно визуально ПЕРЕСОБРАТЬ Home и Calendar значительно ближе к референсам.

Обязательно сначала изучи:

docs/ui/ritela_main.png
docs/ui/ritela_calendar.png
docs/ui/Ritela_UI_Kit.png

Эти изображения важнее текущего вида приложения.

Текущий UI — это implementation source.
Референсы — visual source of truth.

Если текущая структура мешает приблизиться к референсу:
разрешается менять layout/composition существующих composables.

Бизнес-логику и данные сохранить.

==================================================
1. ОСНОВНАЯ ОШИБКА ПРЕДЫДУЩЕЙ ВЕРСИИ
==================================================

Не делай ещё один лёгкий facelift.

НЕ НУЖНО:

"оставить всё как есть +
чуть изменить radius +
чуть изменить colors"

НУЖНО:

перестроить визуальную композицию.

После работы интерфейс должен выглядеть заметно иначе даже при беглом сравнении screenshot before / after.

==================================================
2. СТИЛЬ
==================================================

Целевой стиль:

CELESTIAL-BOTANICAL PREMIUM MINIMALISM

Характер:

- deep plum
- muted wine
- dusty rose
- warm blush
- sage green
- ivory
- soft peach highlights
- subtle celestial glow
- botanical decorative accents
- serif display typography
- restrained fantasy atmosphere

Это НЕ:

- astrology app
- Tarot app
- gothic UI
- sci-fi
- childish fairy theme
- generic Material 3 sample

Это должно выглядеть как дорогой wellness / cycle app
с лёгким fantasy/celestial характером.

==================================================

Текущая hero card слишком светлая и почти сливается с background.

==================================================
7. ORBIT: СДЕЛАТЬ ВИЗУАЛЬНО БОГАЧЕ
==================================================

Текущая orbit слишком тонкая и слабая.

Нужна:

- larger orbit;
- visually centered;
- elegant;
- clearly visible;
- slight glow;
- stronger marker hierarchy.

Orbit занимает заметную часть hero.

Она может быть художественно асимметричной.

Не обязана быть идеальным ellipse.

Но должна выглядеть как единая дизайнерская композиция.

==================================================
8. ORBIT: СМЫСЛ
==================================================

5 semantic markers:

1. Cycle start
2. Follicular
3. Ovulation
4. Luteal
5. End / transition

+

Current day marker.

Никаких текстовых подписей на самой орбите.

Sun:
символ начала цикла / энергии.

Moon:
символ конца цикла / перехода.

Current marker:
отдельная активная точка.

==================================================
9. ORBIT: DECORATIVE LANGUAGE
==================================================

Разрешены очень умеренно:

- 2–4 tiny stars/dust particles;
- soft glow;
- 1–3 stylized leaves;
- moon;
- sun;
- orbit points.

НЕ делать:

- десятки звёзд;
- galaxies;
- astrology symbols;
- zodiac;
- excessive sparkle.

Botanical elements должны быть abstract / elegant.

==================================================
10. ORBIT MOTION
==================================================

Добавить:

sun halo breathing
current marker pulse
orbit opacity breathing
1–2 decorative particles drift

Очень медленно.

4–7 секунд.

NO:
- rotation;
- spinning;
- bounce;
- shimmer loader.

30. ACCEPTANCE CRITERIA
==================================================

Редизайн считается успешным, только если:

- интерфейс визуально заметно отличается от текущего MVP;
- на Home появился deep plum atmospheric hero;
- orbit стала крупнее, богаче и выразительнее;
- появилась celestial-botanical атмосфера;
- большие даты используют serif-style typography;
- Today actions стали polished tiles;
- calendar получил atmospheric header;
- fertile / ovulation window снова светло-зелёное;
- menstruation остаётся dusty rose;
- лишний текст "Лента месяцев" удалён;
- whitespace существенно улучшен;
- Home и Calendar выглядят как один продукт;
- UI ближе к ritela_main.png / ritela_calendar.png;
- build/tests/lint проходят.
