# Стиль Ritela

Зафиксирован 2026-10-05 по макету, приложенному пользователем: тёплая бумага, сливовый акцент, пудровые карточки, крупные даты с засечками и лёгкий ботанический мотив. Это выбранное направление для следующих экранов. Предыдущая зелёная палитра заменена. Значения в коде: `ui/Theme.kt`; изменения палитры согласуются с этим документом.

Основные радиусы 24/32dp, поля 24dp, интервалы 8/16/24/32dp. Большая карточка прогноза — 32dp. Основная кнопка занимает ширину контента, высота не меньше 56dp. Нет тяжёлых теней, чёрных обводок, кислотных акцентов и фоновых фотографий. Цвет дополняет текст/символы, не заменяет их. Динамическая системная палитра по умолчанию выключена: обои не меняют выбранный стиль.

## Типографика и композиция

Системный serif для бренда, крупных дат и заголовков; системный sans для действий, пояснений и числовых данных календаря. Оба поддерживают кириллицу/латиницу, дополнительных загрузок шрифтов нет. Бренд 42sp, дата прогноза использует displayLarge; scaling не отключается. Текст переносится и прокручивается, не обрезается ради сходства с картинкой.

Главная: Ritela → сегодня/локализованная дата → текущий статус или большая оценка следующего начала → основное действие → история. При готовом прогнозе он занимает главный блок вместо дублирования последней записи. Пустое и открытое состояния имеют собственные тексты и действия. Календарь и формы используют ту же тему.

`CycleOrbit` рисует в Canvas ботанический мотив и 28 декоративных точек; точка на окружности соответствует отношению `(day - 1) / medianLength`, ограниченному 0..1. Это не 28 медицински размеченных дней и не фазы цикла. Все значения даны текстом рядом. На узком экране и при fontScale >1.3 декор скрывается, освобождая место данным. Изображение не содержит пользовательских записей и не требует сетевого ресурса.

## Механики макета

Переносим иерархию и внешний вид, сохраняя фактическое поведение. Прогноз сопровождается возможным диапазоном, качеством истории и пояснением; проценты уверенности и фазы по календарной догадке не добавляются. Расчёт: [PREDICTION.md](PREDICTION.md).

Кнопка записи открывает работающую форму; текущую менструацию можно завершить, историю — исправить/удалить. Навигация показывает работающие Сегодня/Календарь. Симптомы, энергия/настроение, insights, настройки и уведомления из макета добавляются вместе с хранением и сценариями соответствующих этапов, без фиктивных значений. Слоганы из изображения не возвращаем: пользователь ранее попросил короткий человеческий текст.

## Два языка

Английский — полный fallback в `res/values/strings.xml`, русский — полный `res/values-ru/strings.xml`. Название Ritela одинаковое. Кнопки, ошибки, календарь, подсказки, plurals и даты локализованы. Даты сохраняются как LocalDate/epoch day независимо от языка.

AGP генерирует localeConfig из resources.properties (`en`) и ресурсов. localeFilters ограничивает APK языками en/ru, включая строки библиотек. Android 13+ предлагает отдельный язык приложения в системных настройках; на API 26–32 используется язык устройства. Отдельного переключателя внутри приложения пока нет. Реализация соответствует [официальной инструкции Android](https://developer.android.com/guide/topics/resources/app-languages); используемый DSL localeFilters описан в [AGP 9.4](https://developer.android.com/reference/tools/gradle-api/9.4/com/android/build/api/dsl/ApplicationAndroidResources).

Новые надписи добавляются сразу на двух языках. Без обещаний диагностики, лозунгов и длинных приветствий. Примеры: «Отметить месячные» / “Log period”, «Изменить даты» / “Edit dates”, «Возможное начало» / “Possible start”.

## Проверка следующего экрана

Проверять настоящие Compose PNG в обеих темах и языках, пустое/заполненное/ошибочное состояние, узкую ширину и fontScale 1.3/2.0. Основное действие доступно через прокрутку, touch targets не меньше 48dp. Декор не занимает место нужного текста. Не принимать совпадение картинки за проверку действий: выполнить запись/правку/удаление и календарный сценарий. Команды и ограничения: [TESTING.md](TESTING.md).
