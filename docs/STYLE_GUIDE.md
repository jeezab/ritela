# Стиль Ritela

Зафиксирован 2026-10-05 по макету, приложенному пользователем: тёплая бумага, сливовый акцент, пудровые карточки, единый sans-serif и лёгкий ботанический мотив. Это выбранное направление для следующих экранов. Предыдущая зелёная палитра заменена. Значения в коде: `ui/Theme.kt`; изменения палитры согласуются с этим документом.

Динамическая системная палитра по умолчанию выключена: обои не меняют выбранный стиль.

## Типографика и композиция

Единый системный sans-serif (FontFamily.SansSerif) для всех надписей: бренда, крупных дат, заголовков, действий и календаря. Шрифты с засечками не используются. Шрифт поддерживает кириллицу/латиницу, дополнительных загрузок шрифтов нет. Бренд 24sp, дата прогноза использует displayLarge (RU 40sp); scaling не отключается. Текст переносится и прокручивается, не обрезается ради сходства с картинкой.

Главная: компактная Ritela/дата без года → статус или прогноз → основное действие → записанное самочувствие → статистика → статьи. История остаётся в календаре. При готовом прогнозе он занимает главный блок вместо дублирования последней записи. Пустое и открытое состояния имеют собственные тексты и действия. Календарь и формы используют ту же тему.

`CycleOrbit` рисует в Canvas ботанический мотив и 12 декоративных точек; точка на окружности соответствует отношению `(day - 1) / medianLength`, ограниченному 0..1. Это не 28 медицински размеченных дней и не фазы цикла. Все значения даны текстом рядом. На узком экране и при fontScale >1.3 декор скрывается, освобождая место данным. Изображение не содержит пользовательских записей и не требует сетевого ресурса.

## Механики макета

Переносим иерархию и внешний вид, сохраняя фактическое поведение. Прогноз сопровождается возможным диапазоном, качеством истории и пояснением; проценты уверенности не добавляются; фазовая метафора подписывается как предполагаемая. Расчёт: [PREDICTION.md](PREDICTION.md).

Кнопка записи открывает полноэкранный календарь диапазона: первый/последний день, выделение всего интервала, быстрый выбор длительности и закреплённое сохранение. Будущие дни заблокированы; окончание можно оставить пустым. Навигация показывает работающие Сегодня/Календарь/Настройки. В настройках язык без пояснения, тема (системная/светлая/тёмная) и экспорт/импорт с необязательным паролем. Тема применяется сразу и сохраняется после перезапуска. Выбор длины цикла отсутствует; длительность календарного прогноза доступна отдельно, default 7. Остальные элементы макета добавляются вместе с хранением/сценариями, без фиктивных значений. Слоганы из изображения не возвращаем.

Календарь содержит семь видимых столбцов без горизонтальной прокрутки, месяцы свободно прокручиваются вертикально в LazyColumn, без paging/snap. Заголовок открывает выбор года из прокручиваемого списка и месяца из сетки 3×4. Главный календарь использует всю ширину с полями 2dp, высота дней ≥56dp и растёт со шрифтом. На 320dp ширина отдельного дня около 45dp: это осознанное исключение из общей цели 48dp, чтобы выполнить требование видеть все дни; горизонтального обрезания нет. При крупном шрифте заголовки недели сокращаются, даты остаются текстом полного размера.

## Два языка

Английский — полный fallback в `res/values/strings.xml`, русский — полный `res/values-ru/strings.xml`. Название Ritela одинаковое. Кнопки, ошибки, календарь, подсказки, plurals и даты локализованы. Даты сохраняются как LocalDate/epoch day независимо от языка.

AGP генерирует localeConfig из resources.properties (`en`) и ресурсов. localeFilters ограничивает APK языками en/ru, включая строки библиотек. Android 13+ предлагает отдельный язык приложения в системных настройках; на API 26–32 используется язык устройства. Отдельного переключателя внутри приложения пока нет. Реализация соответствует [официальной инструкции Android](https://developer.android.com/guide/topics/resources/app-languages); используемый DSL localeFilters описан в [AGP 9.4](https://developer.android.com/reference/tools/gradle-api/9.4/com/android/build/api/dsl/ApplicationAndroidResources).

Новые надписи добавляются сразу на двух языках. Без обещаний диагностики, лозунгов и длинных приветствий. Примеры: «Отметить месячные» / “Log period”, «Изменить даты» / “Edit dates”, «Возможное начало» / “Possible start”.

## Проверка следующего экрана

Проверять настоящие Compose PNG в обеих темах и языках, пустое/заполненное/ошибочное состояние, узкую ширину и fontScale 1.3/2.0. Основное действие доступно через прокрутку, цель touch targets 48dp с описанным выше исключением узкой сетки. Обязательно сравнивать bounds первого/последнего столбцов с viewport, а не принимать частично видимый элемент за корректную сетку. Декор не занимает место нужного текста. Выполнить запись/правку/удаление, вертикальные свайпы, выбор года/месяца и сохранение настроек. Команды и ограничения: [TESTING.md](TESTING.md).

Главная: компактная строка дня цикла без отдельной плашки, орбитальная сцена и прогноз без слова «ориентир» и без «Сроки могут измениться», реальные диаграммы вместо списка истории. Графики содержат даты/числа и текстовый эквивалент; пустые дни не рисуются нулём. Иконки — собственные vector drawables, общий контур 1.8dp и семантический tint. Отметки дня — общий Dialog с FlowRow чипами, масштабируемым шрифтом, прокруткой и закреплённым сохранением. Карточки помощи имеют краткий текст и источник, полный текст открывается по нажатию.

Подписи графика выровнены с точками: шесть последних значений, при fontScale >1.3 — три. Итоговая медиана всё равно использует годовое окно целиком (максимум 12).

## Полировка орбиты 2026-10-07 — текущая версия

Этот раздел заменяет описание органичной орбиты выше. Hero использует surfaceContainerLow с 18% secondaryContainer (rose mist), padding 24dp/20dp, радиус 32dp. Сцена 156dp, при fontScale 1.2–1.5 — 124dp; выше 1.5 декор скрывается в пользу текста. Дата 36sp и данные прогноза сохранены.

Одна непрерывная линия drawOval, stroke 1dp, наклон −10°. OrbitGeometry применяет ту же rotation matrix к координатам всех маркеров. Пять символических вех: солнце 210°, светлая планета 255°, овуляционная жемчужина 320°, приглушённая планета 390°, полумесяц 520°. Углы последовательно проходят конец оборота; это не медицинские границы фаз. Текущий день — кольцо с центром, угол 210° + 360° × clamp((day−1)/length). Первый день совпадает с началом, просроченный цикл не оборачивается. Легенда EN/RU доступна через info.

Дыхание alpha 0.93–1 за 5.2 секунды; pulse текущей точки 0.98–1.04 за 4.2 секунды. Позиции фиксированы, вращения и случайных частиц нет. Полумесяц — вычитание двух кругов без закрашивания орбиты. Кисти/геометрия кешируются, состояния анимаций читаются только при рисовании. Системное отключение анимаций, low-RAM и уход в фон сохраняют статичную сцену.
