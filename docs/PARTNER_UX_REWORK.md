# Partner UX — 2026-10-12

## Поведение

Settings содержит сохраняемые «Мой календарь» / «Режим партнёра», перенос ключей, Bluetooth, независимые grants и единственные технические подробности. Переключение режима не удаляет данные. Выбор контакта сохраняется на локального пользователя. Локальное переименование не меняет личность или grants.

В режиме партнёра Today — последний реально полученный DATA одной личности выбранного контакта, Calendar — read-only MonthGrid, Partner — лента дудлов и ручной обмен. Получатель не вызывает PredictionEngine. День, фаза и орбита привязаны к asOf отправителя; прошедшие дни не экстраполируются. Для группы не смешиваются циклы разных людей. Новые FORECASTS включают calculatedAt, algorithm, cycleLength; старые сообщения читаются без них, без придуманной длины орбиты. Для чтения расширенного пакета старым строгим клиентом требуется обновление обеих сторон. История/дневник сгруппированы, годовые прогнозы доступны через календарь, без списка 12 строк.

Постоянные grants отделены от фактического объёма передачи. Новый editor использует прежний ShareScope: четыре категории, раскрываемые разделы/теги, промежуточное состояние и закреплённые действия. Полный grant секции допускает подмножество её тегов, не соседние секции. Legacy DIARY может быть сужен до granular SECTIONS/TAGS; новый draft не использует blanket DIARY. По умолчанию ничего не выбрано, секс/заметки требуют сознательного выбора. «Выбрать всё» — действие, не permission. Отмена не записывает draft. Перед передачей показаны получатель, количество записей и диапазон дат, есть быстрые варианты цикла/прогнозов.

В ленте только DOODLE, один дудл = одна карточка. ACK/OPENED остаются в протоколе, обновляют Delivered/Opened, не создают карточки. Подготовленный исходящий дудл ожидает отправки; подписанное подтверждение необходимо для заявления доставки/открытия. Миниатюры не раскрывают неоткрытые сюрпризы. QR раскрывается на полный экран, закрытие возвращает исходный QR.

Сердечки быстрее реагируют на наклон (320 вместо 85), не притягиваются к выбранному краю. После ACKNOWLEDGED — зелёная галочка; движение/датчик продолжаются до закрытия. Lifecycle STOP и reduced motion отключают датчик. Параметр стороны остаётся совместимым с протоколом, не влияет на анимацию. Активное соединение отличается от сохранённого доверия и сбрасывается при закрытии сокета.

ACTION_VIEW/ACTION_SEND принимают content URI для application/octet-stream/application/vnd.ritela. Пользователь подтверждает импорт, ограниченный поток читается через ContentResolver; прежние проверки подписи, адресата, доверия и повторов обязательны. Широкие файловые permissions не добавлены. Поддержка всех нестандартных MIME мессенджеров не заявляется.

Включение общего пункта «Дневник» выбирает только разрешённые стандартные разделы настроения, симптомов, энергии и выделений. Секс, заметки и пользовательские разделы требуют отдельного выбора. Явное действие «Выбрать всё» сохраняет возможность осознанно выбрать весь разрешённый объём.

Проверка годовых прогнозов допускает до 366 элементов вместо прежних 16: короткие циклы могут давать больше 16 следующих начал за год. Размер пакета остаётся ограниченным; алгоритм прогнозирования не менялся.

## BLE — исследование

Проверены [официальные разрешения Android Bluetooth](https://developer.android.com/develop/connectivity/bluetooth/bt-permissions) и [модель BLE Android](https://source.android.com/docs/core/connect/bluetooth/ble). Android 12+ требует runtime SCAN/ADVERTISE/CONNECT, отказ от определения местоположения обозначается neverForLocation. Существующий RFCOMM сохраняется, Nearby Connections SDK не добавляется.

Для приватного «Рядом» нужен отдельный короткий foreground-сеанс (например, 10 секунд, остановка на STOP/отмене), случайный непостоянный beacon и аутентификация доверенного устройства. Публичный UUID/SHA и хеш публичного pairing context не являются секретом или доказательством личности. Обнаружение не должно отправлять данные. Новый BLE-протокол и статус «Рядом» в этой доработке не включены: требуется согласование ephemeral-токенов и проверка двух физических телефонов. Фонового сканирования нет; Settings открывает системные параметры Bluetooth.
