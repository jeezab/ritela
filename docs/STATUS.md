# Точка продолжения

Обновлено: 2026-10-05 (Europe/Moscow). Завершена доработка по замечаниям пользователя: нижние настройки, исходный прогноз 28/5, полностью видимая неделя, вертикальные месяцы, выбор месяца/года и удобный ввод диапазона. M0 завершён; M1/M2 имеют рабочую первую версию, MVP ещё не завершён.

## Реализовано

- Нижняя навигация Сегодня/Календарь/Настройки. Настройки сохраняют длину цикла и длительность месячных, предлагают сброс 28/5 и переход к системному выбору языка. Числовые значения в приватных SharedPreferences, StateFlow + combine с Room пересчитывают прогноз без изменения записей.
- Исходный цикл 28 дней, месячные 5 дней. После первого начала доступен стартовый прогноз, включая открытую запись; до трёх интервалов длина цикла берётся из настроек. После первого окончания включительная длительность записи заменяет preset; последующие завершённые записи её уточняют. Стартовая оценка явно подписана, LOW, ближайший диапазон ±4 дня. Без первой даты начала нет точки отсчёта — будущие даты не выдумываются.
- Далее медиана/MAD последних 12 интервалов, расширяющиеся диапазоны до 12 циклов. Невалидная/просроченная история всё ещё подавляет прогноз; автоматического переноса незаписанных циклов нет. PREDICTION.md обновлён. Ожидаемые дни менструации имеют отдельный символ ○, остаются оценками и не сохраняются в Room.
- Календарь: семь столбцов на всю ширину без horizontal scroll/обрезания воскресенья. VerticalPager меняет месяцы вверх/вниз; заголовок открывает список годов и сетку месяцев. Есть стрелки вверх/вниз и возврат к сегодня. Высота дня растёт со шрифтом; на 320dp ширина ниже общей цели 48dp ради полностью видимой недели, это зафиксировано в STYLE_GUIDE и skill.
- Полноэкранная форма: первый/последний день выбираются на одной MonthGrid с выделением диапазона; явный быстрый выбор длительности, снятие окончания «Ещё идут», закреплённая кнопка Save. Picker отдельных дат сохранён как дополнительный способ. Будущие дни заблокированы. Правка/удаление, UUID/createdAt, overlap transaction и schema v1 сохранены.
- Стиль по макету: молочный/сливовый/пудровый, serif-заголовки и даты, sans-действия, адаптивный Canvas-декор; dynamic colors по умолчанию выключены. Полный EN/RU, системный выбор языка Android 13+, на API 26–32 язык устройства. FLAG_SECURE/backup exclusions/no network/no medical logs сохранены. Room без шифрования.
- Исследованы официальные сценарии быстрого ввода Clue/Flo: ссылки и адаптация в UI_DESIGN.md. Установленные версии не проверялись. Документы/карта/решения обновлены; ui-quality-audit и cycle-prediction-validation обновлены до 1.1.0, hashes в lock. Всего 5 project-local skills. Исходные промпты сохранены.
