# Точка продолжения

2026-10-06. Завершена доработка UI по приложенному промпту. Предыдущие коммиты были отправлены в master по запросу пользователя; текущий шаг сохраняется локально, новый push не выполняется.

## Результат

- CalendarScreen: свободная вертикальная LazyColumn, без магнитного paging. Заголовок выбирает месяц/год, Сегодня возвращает к текущему месяцу. Контрастная заливка отмеченных дней, капля/значок записи, отдельные обозначения прогноза. Легенда открывается кнопкой, инструкция о листании удалена. День открывает ModalBottomSheet с подробностями, правкой/удалением периода и самочувствием; история — отдельный список в календаре.
- PeriodEntry показывает занятые дни и блокирует их в сетке и системном picker. periodConflict проверяет весь интервал (включая открытые записи), а не только конечные даты. Собственный UUID исключается при правке. Save отключён для будущих/обратных/пересекающихся дат. Из редактирования доступно удаление с отдельным подтверждением. Транзакционные проверки Room сохранены; схема не менялась.
- Home: шапка 24sp, дата без года; hero компактнее, русская дата с полным месяцем, орбита 64dp рядом с днём цикла. Дата имеет всю ширину. Орбита — 12 нейтральных точек и один текущий маркер, без медицинских фаз. При активных месячных — правка/завершение. Мини-карточки симптомов и outer-card статистики убраны: только записанное состояние, годовые метрики, выводы и sparkline при изменениях. Точка выбирается через значение, дата показана для выбранного измерения. Расчёты измерений вынесены в domain/MeasuredSeries.kt.
- Settings: сгруппированный список и dialog темы. Радиусы 12/16/20/32; bottom navigation цвета страницы; карточки помощи 228dp/две строки. Сохраняются RU/EN, sans, палитра, функциональность языка/темы/backup.
- help_reviewed удалён из обеих локалей и UI. help_condoms_body EN/RU уточнён и сверён по NHS 2026-10-06. В календаре вероятность беременности показана как «Недостаточно данных»: календарные даты не дают обоснованного процента или safe days; источник NHS открывается по нажатию.
- Исходный промпт сохранён в docs/prompts/2026-10-06-ui-polish.txt. Карта, стиль, решения, архитектура, медицинские источники и проверки обновлены. preview-ui.ps1 -CompareBefore создаёт семь пар до/после без нового render.
