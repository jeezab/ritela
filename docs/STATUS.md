# Точка продолжения

Обновлено: 2026-10-05 (Europe/Moscow). M0 завершён. Три согласованных пользователем шага выполнены: главная/форма/текст, правка/удаление, первая версия календаря/прогнозов. MVP ещё не завершён.

## Реализовано

- Главная «Сегодня»: выделенная текущая/последняя запись, день цикла, основное действие, полный диапазон дат, компактная история последних 30 записей. Слоганы и повторяющиеся подписи убраны. Светлая/тёмная темы, системные dynamic colors сохранены.
- Общая форма записи/правки: широкие кнопки дат (min 56dp), прокрутка, основная кнопка сохранения, снятие окончания «Ещё идут». Picker исключает будущие даты и окончание раньше начала. Состояние формы восстанавливается после Activity recreation.
- Room/repository: add/finish/edit/delete; UUID/createdAt сохраняются при правке. Проверка пересечений и UPDATE в транзакции, finish защищён от конкурентной смены начала. Удаление с подтверждением/отменой. Схема v1 сохранена без destructive fallback.
- Календарь: месяц с понедельника, стрелки/свайп на обычной ширине, возврат к сегодня, выбор дня, просмотр/правка/удаление связанной записи, добавление прошлой даты. Будущие дни только для просмотра. На узком экране горизонтальная прокрутка сетки сохраняет touch targets >=48dp; месяц меняется стрелками. Нижняя навигация Сегодня/Календарь.
- Чистый Kotlin domain: день цикла, медиана/MAD последних 12 интервалов, минимум три интервала, качество истории и расширяющиеся диапазоны до 12 циклов. Нет процентов точности, овуляции или выдуманных прошедших циклов. При открытой/некорректной/недостаточной истории и просроченном ближайшем диапазоне прогноз скрыт с объяснением. Все формулы и инженерные ограничения: PREDICTION.md.
- Room Flow пересчитывает прогноз после операций; ON_RESUME обновляет сегодня. Календарь/расчёт получают всю историю; лимит 30 относится только к списку главной. Производные прогнозы не хранятся.
- FLAG_SECURE, backup/transfer exclusions, отсутствие сети и медицинских логов сохранены. Данные локально в Room; шифрования базы пока нет.
- preview-ui.ps1 создаёт HTML-галерею настоящих Compose renders на синтетических данных без телефона. Сейчас 16 PNG, включая календарь light/dark и 320dp/fontScale 1.3/2.0. CI формирует ту же галерею внутри verification-reports. Есть IDE previews.
- Исходные промпты/роль сохранены; карта, решения, архитектура и проверки обновлены. Добавлен cycle-prediction-validation через skill-creator; всего 4 project-local skills с hash registry.

## Ограничения

Это первая версия календаря/прогнозов, не законченный дизайн всего продукта. Диапазоны — эвристика по истории без клинической валидации. Нет дневной интенсивности/симптомов, экспорта/импорта, app lock и шифрованного backup. При изменении schema v1 обязательны migration/tests. Device smoke test и TalkBack не проверены; JVM render не заменяет устройство. Галерея статическая; для нажатий нужен эмулятор или устройство. Debug APK не является release/MVP. Push в этой сессии не выполнялся.
