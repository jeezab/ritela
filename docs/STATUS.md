# Точка продолжения

Обновлено: 2026-10-05 (Europe/Moscow). M0 завершён, M1/M2 имеют рабочую первую версию. По новому макету пользователя перенесён выбранный стиль и добавлен полный русский/английский интерфейс. MVP ещё не завершён.

## Реализовано

- Стиль зафиксирован в STYLE_GUIDE.md и AGENTS: молочный фон, сливовые действия, пудровая карточка, serif-заголовки/даты и sans для действий/пояснений. Theme.kt — общие tokens. Dynamic colors по умолчанию выключены; тёмная тема сохраняет направление.
- Главная: бренд/дата, текущая запись или готовый прогноз в большом блоке, отдельное основное действие, история. Прогноз содержит день цикла, крупную локализованную дату, возможный диапазон, качество истории и источник оценки. Адаптивный Canvas-мотив с кольцом/листом скрывается на узкой ширине или fontScale >1.3. Фазы, симптомы и графики из макета не подставляются без механик.
- Полный English fallback в values и русский в values-ru: формы, ошибки, календарь, plurals и даты. AGP generateLocaleConfig + localeFilters en/ru; сгенерированный config действительно содержит только en/ru. Android 13+ поддерживает системный выбор языка приложения, API 26–32 язык устройства. Внутреннего переключателя нет.
- Периоды add/finish/edit/delete; единая форма дат, транзакционная защита пересечений, UUID/createdAt сохраняются, удаление с подтверждением. Schema v1 не менялась. Календарь читает всю историю, главная выводит последние 30 записей; будущие даты только для просмотра.
- Чистый Kotlin forecast: день цикла, медиана/MAD, минимум три интервала, расширяющиеся диапазоны до 12 циклов; подавление при недостаточной/открытой/невалидной истории и просроченном диапазоне. Формулы PREDICTION.md, производные значения не хранятся. Room Flow и ON_RESUME обновляют расчёт.
- Сохранены FLAG_SECURE, запрет backup/transfer, отсутствие сети и медицинских логов. Room локально без шифрования.
- Галерея preview-ui.ps1: 25 Compose PNG на синтетических данных, EN/RU light/dark/forecast/forms/calendar/narrow. CI собирает ту же галерею внутри verification-reports. Карта/архитектура/решения/README обновлены, добавлен ui-quality-audit; 5 локальных skills с hash registry. Исходные промпты сохранены.

## Ограничения

Макет адаптирован к работающим сценариям, не ко всему будущему продукту. Нет симптомов/дневной интенсивности, insights/settings, уведомлений, экспорта/импорта, app lock и шифрованного backup. Прогноз — инженерная эвристика без клинической валидации. Device smoke test/TalkBack/системный языковой переключатель на устройстве не проверены; эмулятор не установлен. Галерея статическая, для нажатий нужен эмулятор/устройство. Debug APK не release/MVP. Push не выполнялся.
