# Приватность

В текущем APK нет аккаунта, сетевого разрешения INTERNET, рекламного или аналитического SDK. Приложение ещё не хранит пользовательские записи.

MainActivity включает FLAG_SECURE: содержимое окна защищено от обычных системных снимков экрана и отображения в обзоре последних приложений. Системный backup отключён; правила Android 12+ исключают все доступные домены из cloud backup и device transfer. Это проверяется по manifest и JVM-тестом стартового Activity.

После добавления хранения отдельно проверяются база, логи, экспорт, временные файлы и восстановление. Защита от извлечения данных на скомпрометированном устройстве, блокировка приложения и зашифрованный экспорт пока не реализованы. Снимки для проверки UI создаются из пустого экрана с синтетическими данными.
