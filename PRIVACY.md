# Приватность

В текущем APK нет аккаунта, сетевого разрешения INTERNET, рекламного или аналитического SDK. Записи периодов и отметки дня, включая секс и заметки, хранятся в Room/SQLite `ritela.db` в приватной директории приложения. В production-коде нет логирования дат, записей и ошибок с чувствительными значениями.

MainActivity включает FLAG_SECURE: содержимое окна защищено от обычных системных снимков экрана и отображения в обзоре последних приложений. Системный backup отключён; правила Android 12+ исключают все доступные домены из cloud backup и device transfer. Это проверяется по manifest и JVM-тестом стартового Activity.

База пока не зашифрована; её защита опирается на Android sandbox, отключённый backup и защищённое окно. Защита от извлечения данных на скомпрометированном устройстве, блокировка приложения пока не реализована. Экспорт — зашифрованная паролем копия через выбранный пользователем файловый провайдер; облачный провайдер может хранить выбранный файл. Статьи доступны офлайн, ссылка открывает внешний браузер по нажатию. Партнёрский доступ отсутствует. Снимки для проверки UI создаются только с синтетическими данными.

Формат копии, ограничения и восстановление: [BACKUP.md](docs/BACKUP.md). Пароль копии не сохраняется и не восстанавливается. Нет широких разрешений на хранилище; данные статей не используются для сетевого запроса по симптомам.
